Presentation
------------
This directory contains tools for simulated data:

1) **irregular_dafne1** takes the dataset [1] as input and formats it to be loaded with other parts of our software.
2) **irregular_dafne2** takes the fresco models from [1] as input and generates data with simulated degradations on both fresco models (noise, etc.) and fragment images (noise, spatially variable erosion, irregular fragment, etc.).
3) **regular** takes the fresco models from [1] as input and generates data wit simulated degradations on fragment images with rectangular shape (erosion, etc.).
