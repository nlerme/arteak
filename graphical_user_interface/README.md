Presentation
------------
This directory contains a graphical user interface written in **MATLAB** that can be used for multiple tasks

* Blind / non-blind fresco reconstruction.
* Loading / saving of fresco reconstructions.
* Qualitative / quantitative comparison of fresco reconstructions.
